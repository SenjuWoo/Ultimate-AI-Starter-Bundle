# PROMPTS

Standalone prompts, not installed automatically. Skyrim prompt packs live in Skyrim Forge (`docs/prompts`).

For ordinary work, use the short cross-provider prompts. Paste-ready files; the guide explains when to use each:

- [GENERAL-1-START-AND-FINISH.txt](GENERAL-1-START-AND-FINISH.txt) — start and finish a project in one chat (the New chat prompt)
- [GENERAL-2-ARCHITECT-PLAN.txt](GENERAL-2-ARCHITECT-PLAN.txt) — plan only; a second chat builds from PLAN.md (the Plan prompt)
- [GENERAL-3-WORKER-EXECUTE.txt](GENERAL-3-WORKER-EXECUTE.txt) — execute a finished plan / resume unfinished work (the Resume prompt)
- [GENERAL-4-USAGE-LIMIT-RESUME.txt](GENERAL-4-USAGE-LIMIT-RESUME.txt) — a usage limit cut the last chat short; resume efficiently

See [START-RESUME-UPGRADE.md](START-RESUME-UPGRADE.md) for the full guide, including the Upgrade audit prompt for a newer model taking over a project. The installed instructions carry the detailed rules; a prompt only says what this chat is for, in what order to work and what finished means.

The **operating contract** no longer lives here: the default is
`../0-UNRESTRAINT-PACKS/AIO-INSTRUCTION.md`, installed by `INSTALL-AIO.ps1`.
Smaller opt-in variants for constrained hosts sit beside it
(`AIO-INSTRUCTION — Compact.md`, `AIO-INSTRUCTION — Web.md`) - copy manually if wanted.
