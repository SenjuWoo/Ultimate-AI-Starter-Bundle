# PROMPTS

Standalone prompt packs (Skyrim workflows etc.). Not installed automatically.

For ordinary work, use the short cross-provider
[new-chat and usage-limit-resume prompts](START-AND-RESUME.md). Add the actual
task instead of repeating the entire installed operating contract.

The **operating contract** no longer lives here: the default is
`../0-UNRESTRAINT-PACKS/AIO-INSTRUCTION.md`, installed by `INSTALL-AIO.ps1`.
Smaller opt-in variants for constrained hosts sit beside it
(`AIO-INSTRUCTION — Compact.md`, `AIO-INSTRUCTION — Web.md`) - copy manually if wanted.
