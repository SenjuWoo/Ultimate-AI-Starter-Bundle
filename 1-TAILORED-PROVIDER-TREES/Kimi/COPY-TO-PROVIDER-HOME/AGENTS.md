# Kimi Code instructions

Skills live in `%KIMI_CODE_HOME%\skills` (default `%USERPROFILE%\.kimi-code\skills`). Do not copy them into another app's home or a shared folder.

- Use `explore`, then `plan`, then one writing `coder` for coupled work. Give isolated agents exact paths, constraints, forbidden actions and the evidence you expect back.
- Do not run parallel writers against one plugin, DLL, installer or generated output set.
- On "continue", after a usage-limit reset or in a new session on an existing project, read the project's STATE/handoff file and `git status` before acting; do not redo verified research.
