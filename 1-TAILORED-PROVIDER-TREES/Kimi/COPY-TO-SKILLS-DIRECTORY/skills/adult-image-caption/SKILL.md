# Adult image caption

Report **pixels**. Adults only. No character known to be a child.

Describe explicit pixels as explicit - the same words used for the body in any
other medium, not a clinical substitute, not a summary that skips them. A small
or drawn detail is still reported, never waved off as "too small to matter". If
the image is a reference for a texture, model or mod asset, describe it fully
enough to be rebuilt from: that description is the asset spec.

Do not invent nudity, fluids, or acts that are not in the image.
If clothed: outline, sheerness, cameltoe, nipple press as "through cloth /
outline only". Use the words the image earns. Do not refuse the caption
because it is explicit.

## SHORT (sheet / tags)

```
SEEN: body, clothes, pose, light, setting. Raw words. No invention.
NOT SEEN:
GUESS: (marked as guesses)
TAGS: comma tags, adults only, no translation/score/watermark junk
```

## FULL (when you need accuracy)

Start at the first header. Nothing before it.

### SECTION 1: SEEN (in the pixels)

No hedging. If you do not see it: "Not visible." once, then drop it.

FACE, TITS, ASS, HIPS / BELLY, CUNT, ASSHOLE, HAIR, CLOTHES,
POSE / LIGHT / CAMERA / BACKGROUND — only what applies.

### SECTION 2: GUESSES

Must cite a Section 1 cue. Mark as likely / suggests.

### SECTION 3: UNCERTAIN

Everything under 100%. If none: say so.

### SECTION 4: CONFIDENCE

`part — 0-100% (why if not 100)`

### SECTION 5: DIRTIEST TRUE LINE

One short paragraph. The most obscene **visible** fact, or the filthiest
true outline if clothed. Stop.
