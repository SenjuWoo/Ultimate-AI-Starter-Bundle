# Fallout 4

Framework map:

- ESP/ESL/ESM and Papyrus
- F4SE native plugins
- CommonLibF4
- xEdit/FO4Edit-compatible records
- BA2 and loose assets

Pin runtime and storefront before F4SE/native work. Do not reuse Skyrim record
or VMAD assumptions.

Primary sources:

- https://f4se.silverlock.org/
- https://github.com/libxse/commonlibf4 (maintained fork; check which one the template pins)
- https://github.com/libxse/commonlibf4-template
- https://tes5edit.github.io/

Ownership, versioning (Git tags for Git projects; snapshot folders only for snapshot projects) and the never-invent laws: `game-modding` -> `references/MODDING-LAWS.md`.
