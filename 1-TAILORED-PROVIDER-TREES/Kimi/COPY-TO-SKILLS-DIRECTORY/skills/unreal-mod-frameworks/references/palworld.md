# Palworld

Framework map:

- UE4SS Lua/C++
- generated SDKs/reflection
- PalSchema when explicitly targeted
- cooked Unreal assets and PAK content
- official Workshop paths when applicable

Major updates can invalidate loaders, signatures, SDKs, and cooked assets.
Verify current compatibility before reusing old layouts.

Primary sources:

- https://github.com/UE4SS-RE/RE-UE4SS
- https://pwmodding.wiki/
- https://github.com/Okaetsu/PalSchema

Ownership, versioning (Git tags for Git projects; snapshot folders only for snapshot projects) and the never-invent laws: `game-modding` -> `references/MODDING-LAWS.md`.
