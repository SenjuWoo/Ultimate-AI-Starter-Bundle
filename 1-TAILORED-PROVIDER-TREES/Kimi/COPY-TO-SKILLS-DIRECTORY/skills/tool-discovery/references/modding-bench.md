# Modding workbench companions

The [Starter Bundle](https://github.com/SenjuWoo/Ultimate-AI-Starter-Bundle) supplies common build tools, AI provider setup, Universal Modder recon and shared asset workflows.

[Reverse THIS!](https://github.com/SenjuWoo/reverse-this) owns installed decompilers, debuggers, analysis tools and REA. Resolve its kit.json pointer and installed.json manifest; catalog entries alone do not prove installation. Its AGENTS.md provides current shims, prerequisites and boundaries.

[Skyrim Forge](https://github.com/SenjuWoo/SkyrimForge) owns Skyrim tools and specialist skills, including houseCARL, xEdit, LOOT and Creation Kit integration. Resolve SKYRIM_FORGE_ROOT and read its instructions.

These repositories cooperate without rewriting one another’s settings. Game installs, mod-manager staging, saves, references and private analysis stay outside source releases. Never duplicate a tool merely because it is outside the bundle folder.
