Resolve exact Unreal/game/UE4SS versions, installation layout, generated SDK,
mapping files, signatures, and whether the task belongs in Lua, C++, Blueprint,
cooked assets, or data.

Never invent reflected properties or hook signatures.

- https://github.com/UE4SS-RE/RE-UE4SS
- https://docs.ue4ss.com/

Ownership, versioning (Git tags for Git projects; snapshot folders only for snapshot projects) and the never-invent laws: `game-modding` -> `references/MODDING-LAWS.md`.
