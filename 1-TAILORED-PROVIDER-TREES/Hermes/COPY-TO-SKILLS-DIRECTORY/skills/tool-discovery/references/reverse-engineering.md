# Reverse-engineering tools

[Reverse THIS!](https://github.com/SenjuWoo/reverse-this) owns REA and the specialist analysis toolchain. Read its AGENTS.md and docs/reverse-engineering.md. Resolve the existing kit through `%LOCALAPPDATA%/ReverseThis/kit.json`, then its installed manifest and named shims. Do not scan the disk or run provider setup.

The Starter Bundle owns common compilers and shared AI tooling. Use `um` for generic game recon. Use [Skyrim Forge](https://github.com/SenjuWoo/SkyrimForge) for Skyrim-specific work. Keep each specialist installer in its owner repository.
