# No Man's Sky

Pin the game build and matching MBINCompiler. Preserve source EXML and patch
scripts. Since game 5.5 a mod is a sub-folder of `GAMEDATA\MODS` with loose MBIN
files; older builds took `.pak` files in `PCBANKS\MODS` (AMUMSS README). Validate
template paths, property names, generated MBIN output, mod folder placement, conflict/merge behavior, localization, and update migration.

Primary community tool sources:

- https://github.com/monkeyman192/MBINCompiler
- https://github.com/HolterPhylo/AMUMSS
