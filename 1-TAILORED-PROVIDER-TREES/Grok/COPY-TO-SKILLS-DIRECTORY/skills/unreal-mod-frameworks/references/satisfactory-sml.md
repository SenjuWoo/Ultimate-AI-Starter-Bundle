# Satisfactory

Pin game branch, SML version, Unreal toolchain, starter project, and community
resources. Stable and Experimental branches are not interchangeable.

Primary sources:

- https://docs.ficsit.app/satisfactory-modding/
- https://github.com/satisfactorymodding/SatisfactoryModLoader
- https://github.com/satisfactorymodding/SatisfactoryModManager

Ownership, versioning (Git tags for Git projects; snapshot folders only for snapshot projects) and the never-invent laws: `game-modding` -> `references/MODDING-LAWS.md`.
