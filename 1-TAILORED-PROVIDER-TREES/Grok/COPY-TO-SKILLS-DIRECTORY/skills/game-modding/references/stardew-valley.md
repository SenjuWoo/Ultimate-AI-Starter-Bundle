# Stardew Valley

MonoGame/XNA with SMAPI (C# mods and Content Patcher packs), not Unity or BepInEx.

Pin game and SMAPI versions. Validate manifests, unique IDs, dependencies,
content invalidation, save migration, config, and cross-platform paths.

Primary sources:

- https://smapi.io/
- https://github.com/Pathoschild/SMAPI
- https://stardewvalleywiki.com/Modding:Index

Ownership, versioning (Git tags for Git projects; snapshot folders only for snapshot projects) and the never-invent laws: `game-modding` -> `references/MODDING-LAWS.md`.
