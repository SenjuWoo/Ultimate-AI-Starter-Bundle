# Unity / BepInEx / Harmony mod development

framework, reference assemblies, Harmony/MonoMod versions, client/server
symmetry, and AssetBundle/Addressables behavior.

Do not mix Mono and IL2CPP templates.

- https://github.com/BepInEx/BepInEx

- https://github.com/pardeike/Harmony

Ownership, versioning (Git tags for Git projects; snapshot folders only for snapshot projects) and the never-invent laws: `game-modding` -> `references/MODDING-LAWS.md`.
