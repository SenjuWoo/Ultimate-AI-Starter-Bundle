# Harmony patch order and safety (cross-game)

Verify target assembly versions, exact method signatures, overloads, generics,
priority, before/after constraints, and runtime type. Never reuse a transpiler
without checking the exact IL shape.

Official source: https://github.com/pardeike/Harmony

Ownership, versioning (Git tags for Git projects; snapshot folders only for snapshot projects) and the never-invent laws: `game-modding` -> `references/MODDING-LAWS.md`.
