# Cross-game error registry and lessons

The registry is embedded in `references/`.

Read `GLOBAL-LESSONS.md`, search `ERROR-REGISTRY.json`, and load only relevant
entries.

Ownership, versioning (Git tags for Git projects; snapshot folders only for snapshot projects) and the never-invent laws: `game-modding` -> `references/MODDING-LAWS.md`.

## Evidence ladder

1. `user-confirmed-runtime`
2. `runtime-evidenced`
3. `tool-validated`
4. `assistant-claimed`
5. `contradicted`

Write candidate lessons to the active project's `MEMORY/CANDIDATES.md`.
