# Source project ownership

This Git repository is the single source owner of the Starter Bundle. Active source is this root; `VERSION.txt` supplies its semantic version and Git tags preserve releases. Keep the existing layout and historical checkout folder name.

This is an established public repository. The user authorized its maintenance, scoped commits/pushes, README/changelog updates and releases. Preserve the current remote, visibility, personal settings and previous releases. That permission does not apply to new user projects: they remain local/private until publication is requested.

Installed provider homes, tool installations, game folders and supplied references are separate inputs. Deployment requires the existing explicit scope and backups. Project ownership/STATE/PLAN/changelog/validation records remain source metadata; product release ZIPs use their delivery manifest and runtime/skill/template/license payload, never a copy of the working directory.
