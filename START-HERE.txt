Ultimate AI Starter Bundle V8.37.11 - START HERE
================================================

WHAT THIS IS
------------
A one-click setup for AI coding apps on Windows. Claude Code, Codex, Grok,
Kimi, Hermes and Google Antigravity get the same skills, tools and
instructions, and learn where your games, mods and tools live.

For a new game or app, ask the AI to use `game-dev-starter`: it picks a free
stack (Godot, Phaser, Three.js, Pygame, LOVE, Bevy, Tauri, FastAPI), routes to
free procedural asset tools, and requires a real build/test harness.


WHAT YOU NEED
-------------
- Windows 10 or 11 and an internet connection.
- At least one of those AI apps already installed. The installer finds them.
- Free disk space: the compiler suite it adds can take several GB.
  Skip it with: START-HERE.bat -SkipBuildTools


INSTALL IN 3 STEPS
------------------
1. Unzip the release you downloaded (you are probably reading this inside it).
2. Double-click START-HERE.bat.
   If Windows warns about the file, choose Run (or More info, then Run anyway).
   Allow administrator rights if it asks.
3. When the window says INSTALL COMPLETE, close and reopen your AI apps.

That is all. Then tell your AI what you want to build or mod; it starts the
project tools a task needs by itself.

The installer leaves running AI apps open. If Hermes is open, native plugin
refresh and profile migration are deferred; existing plugins and skills stay.
For a fresh setup or profile changes, run installation with Hermes closed.


AFTER INSTALLING
----------------
Update ............... double-click START-HERE.bat again. It installs a newer
                       release first (SHA-256 checked) and keeps your settings.
Skyrim modding pack .. automatic when Skyrim, a mod manager or Forge is found
                       (Skyrim Forge, houseCARL, 48 Skyrim skills)
Turn it off again .... START-HERE.bat -ExcludePacks skyrim
Reverse engineering .. automatic when Reverse THIS! is already registered
Force a layer on ..... START-HERE.bat -Packs skyrim,reverse
Only some apps ....... START-HERE.bat -Providers Claude,Codex
Skip optional extras . START-HERE.bat -CoreOnly
                       (also skips the local code graph; re-add it with
                        START-HERE.bat -Components codebase-memory)
Check the install .... run START-HERE.bat again; its last step checks
                       everything it installed and prints PASS or the problem.

Pack choices are remembered for the next run.

Your own settings, instructions and model choices are kept, and config files
are backed up before any change. There is no one-click uninstaller yet.


IF SOMETHING GOES WRONG
-----------------------
- The window shows [ERROR]. Open this file to see what failed:
      %LOCALAPPDATA%\Ultimate-AI-Starter-Bundle\logs\INSTALL-FAILED.txt
  Fix that, then run START-HERE.bat again.
- Grok shows an "unknown" model:
      powershell -NoProfile -ExecutionPolicy Bypass -File .\TOOLS\Ensure-Headroom-Grok.ps1 -Repair
- More fixes: README.md, section "Troubleshooting".


OPTIONAL
--------
Personal profile: write how you like to work in
%USERPROFILE%\.uabs\profile\PROFILE.md. Each install adds it, plus a map of
this PC's game, mod and tool folders, to every AI app. Start from a template:
    START-HERE.bat -ProfileTemplate autonomous-builder

Web chats with no instruction file (ChatGPT, Gemini): paste
3-PREAMBLES\MANUAL-PASTE.txt into the custom-instructions box.

Nothing here yet? INSTALL-REMOTE.bat downloads the latest release, then
installs it.


WHAT IS IN THIS FOLDER
----------------------
    START-HERE.bat        the installer - the only thing you need to run
    INSTALL-REMOTE.bat    downloads the latest release first, then installs
    README.md             full guide and reference
    BOOTSTRAP.txt         a prompt that lets an AI agent install this for you
    0-UNRESTRAINT-PACKS\  no-holds prompt library, adults only (start at its README.md)
