# Whole-bundle workflow audit - 2026-10-22

Scope: installer/update paths, six provider trees, canonical skill discovery,
native plugin ownership, toolbox lifecycle/routing, hooks, Hermes compression,
offline integrity, upstream pins and release gates. One desktop user with
several AI apps and concurrent chats. Vendored engines and every model were
not individually benchmarked.

## Fixed

- Toolbox replayed a mutating call after its child wrote successfully then
  disconnected. A real stdio fixture recorded two writes. It now retries only
  explicitly read-only tools; other lost replies report an unknown outcome.
- Startup timeouts previously stopped waiting without cancelling initialize.
  Cancellation now tears down the child transport; a hung-handshake fixture
  verifies completion within four seconds after a 0.3-second test deadline.
- HTTP sets bypassed project/environment prerequisites. They now use the same
  checks as stdio sets. No authenticated remote operation was exercised.
- The component updater could overwrite a pinned offline asset with newer
  bytes while leaving its checksum unchanged. A real-file fixture proves
  mismatches preserve the last good file; failures now stop InstallAfter.
- Freshness reporting now recognizes security holds as well as compatibility
  holds. Held tools stay held; no forced API migrations.
- Optional Comfy CLI help crashed when redirected through Windows cp1252.
  Process-local PYTHONUTF8=1 fixes the reproduced workflow.

## Efficiency and quality

174 capabilities remain available (125 general, 49 optional Skyrim). Before
this audit the canonical body auditor reported six oversized skills; upstream
reference extraction reduces that to four. Skill bodies load when selected;
aggregate body sizes and schema bytes are not billed-token measurements.
The new Superpowers references retain the material moved out of the bodies.
No model downgrade, reduced reasoning effort, disabled validation or more
aggressive compression was introduced. Existing operator choices stay intact.

Hermes' installed compressor supports the 320,000-token cap and clamps it to
the active window; the main-model auxiliary route avoids a weaker summary
model. This audit does not establish a universally optimal threshold or an
intelligence score. Existing truncation/pruning settings remain visible user
choices; source/config checks do not certify recall on every task.

The installed-state audit found a stale 8.20.0 ledger and a modified duplicate
Codex skill-creator. The ownership-aware installer must reconcile these with
backups. Task-specific machine-wide MCP registrations were absent.

Impeccable malformed-tag security fixtures and the documented sequential
Superpowers browser integration runner pass. Dependency freshness: 22 current,

Not certified: model inference quality, paid services, browser/editor actions,
game runtime, GPU generation, or billed savings. A complete audit cannot
promise zero bugs or that a prompt bundle increases a model's intelligence.
