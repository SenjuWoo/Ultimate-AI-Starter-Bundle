## 8.52.0 (2026-11-15)

- **A forge can register itself.** A forge that ships `uabs-companion.json` in its
  root (`{"schema": 1, "id": "<id>", "entry": {...}}`) is detected, gets its
  commands by name and is doctored with no row in the bundle, so a new forge, or a
  new doctor or launcher in an existing one, no longer needs a bundle release. For
  the same repository the forge's own description wins over the bundle's row. The
  trust rules are unchanged and three are added: the manifest must sit in a folder
  named after its repository, it cannot take an id the bundle gives to another
  repository, and it cannot reuse a command name. A manifest that fails is listed
  by `companion_registry.py --verify` and changes nothing.
  `companion_registry.py --print-manifest <id>` prints a bundled row in that shape
  for a forge to adopt. `UABS_NO_LOCAL_COMPANIONS=1` turns the lookup off.
- **A defect found in a forge is recorded, not patched and not dropped.** A session
  that hits a bug in a forge or tool it is only using runs
  `python TOOLS/field_report.py <owner-id> --title "<what failed>"` (with
  `--command`, `--expected`, `--actual`, `--workaround`). It appends one entry to
  `FIELD-REPORTS.md` in that owner's source folder, counts a repeat instead of
  duplicating it, replaces the home folder with `~`, and lists the file in
  `.git/info/exclude` so it never reaches a commit. `--list` shows the open reports
  on the machine; `bundle` is a valid owner. The installed contract, its compact
  form, `ai-tooling-stack` and the forge standard carry the rule: the using session
  records and works around; the forge's own maintainer session reads the file
  first and deletes what it fixes.
- **MarvelRivals-Forge joins the companion registry and forge routing.** The
  owner's Marvel Rivals skin-mod toolkit (`SenjuWoo/MarvelRivals-Forge`, CLI
  `mrforge`, skill `marvelrivals-forge`) is detected like the other forges, gets
  an `mrforge` command that Git Bash can call too, and has a row in
  `ai-tooling-stack` (`mrforge doctor`, then `mrforge plan "<task>"`).
- `ai-tooling-stack` now says a routing row can lag its forge: the installed
  forge's own skill, `doctor`, `capabilities` and `guide` are current.

The bundle still ships 81 canonical skills.
