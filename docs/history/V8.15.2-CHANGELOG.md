## The refresh tool now owns the skill-side deltas

Refreshing used to re-copy upstream's skill references verbatim, which would
have silently undone a bundle decision: upstream's `reverse-engineering` skill
ships a small `unpack_upk.py` fallback, and the bundle deliberately does not
redistribute it (it allocates from package-declared sizes and overwrites its
output without bounds or overwrite protection), with two files written to say
so. Upstream has since *moved* that file, so a mirror-only refresh would have
reintroduced it and dropped the wording.

`TOOLS/refresh_universal_modder.py` now carries `SKILL_DROP`,
`SKILL_OVERRIDES` and `SKILL_PATCHES`: every refresh removes that file again,
restores the bundle's README and guide line, and - this is the point - exits
non-zero on any patch or delta that no longer matches. A refresh that misses a
hunk fails loudly instead of shipping a regression. The first dry run proved
it: the drop key pointed at the old path and the tool refused to write until
the key was corrected to the moved location.
