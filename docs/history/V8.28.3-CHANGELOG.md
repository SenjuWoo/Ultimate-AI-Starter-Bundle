# v8.28.3 - live-gateway install and toolbox scoping

Skill payload: 127 canonical skills, six provider trees.

The local 8.28.2 install reached the native-plugin stage and aborted because
this chat was a live Hermes gateway session. The installer was right not to
kill it, but aborting the whole run is a hard blocker. The general `toolbox`
server also carried Skyrim paths even when the pack was off.

- `INSTALL-AIO.ps1` now defers the Hermes native plugin refresh when the
  gateway has a live session: it warns, records `deferred-live-gateway`, keeps
  the copied skills and continues the install. A restart can finish the
  refresh.
- `TOOLS/Add-Reasoning-MCPs.ps1` passes the Skyrim environment variables to
  `toolbox` only when `SKYRIM_FORGE_ROOT` exists, so a disabled pack leaves no
  Skyrim state on a general server.
- Validation: the shared-Python fix from 8.28.2 still passes, contracts and
  the full Windows pack gate run before the release.
