## 8.50.0 (2026-11-14)

- **Cyberpunk routing follows Cyberpunk Forge 0.3.0.** The forge now plans and
  documents new drivable cars and bikes (`cpforge knowledge vehicles`: copy a
  vanilla car of the same layout, its rigs and additive door/hood/trunk clips,
  the model frame, bone-local part meshes, light zones, WolvenKit import), checks
  `.tweak` files, flags engine natives vanilla never declares, and diffs the
  script API between game patches. `ai-tooling-stack`'s Cyberpunk row and the
  companion registry name the vehicle start point and the patch diff, and the
  registry says to re-run the forge's `Install.ps1` after updating its checkout so
  the installed `cyberpunk-forge` skill matches the code.
- The registry notes that the forge reads `WOLVENKIT_CLI` before its own fallback
  folder. The bundle points that variable at the live Reverse THIS kit, so an
  older kit copy left in the default install folder is not used.

The bundle still ships 81 canonical skills.
