## 8.20.0

- **New skill `game-mashup-passthrough`.** The lessons from a working lab build of a cross-engine mashup (host game A draws game B's characters) are now a skill that loads on its own when you ask for one: pick passthrough over loading foreign assets, check anti-cheat/DRM first, spike the draw/UI split and the animation decode before features, oracle before renderer, command file before features, a paired unfreeze for every freeze, manifest-driven extraction, small agent tasks with a commit per step, and the Windows shell traps hit along the way. It does not select Melty or any publishing platform.
- **The mashup card grew.** `project-intel/references/game-mashup-melty.md` gains a "Drawing under the UI" section (how the host's frame splits scene and UI, the recomposite formula, ReShade 6.8 add-on hook points, why a copied `.fx` needs a reload), texture/hair/brow rules, the spike order and the freeze/teleport traps. The router row now names passthrough work. Offsets, install paths, log paths and the launch URI from the source file stay private on purpose.
- **Universal Modder `6a8865a` -> `c1dff21`.** 28 upstream commits: new `um voidless` (2D sprites from a paid API; its key reuses the pack's hidden-key helpers), a window-capture escape fix, a publish check that no longer flags a mod's own installed copy as game files, and about twenty new game notes, among them depth compositing with a ReShade add-on and two passthrough write-ups. The changed code was read before it was kept; all 20 pack patches re-applied; wheel rebuilt byte-identically twice (3.6 MB).
- **Security: Pillow 13.0.0 and certifi 2026.10.19.** Pillow 13.0.0 (2026-10-16) fixes three advisories (an unbounded-recursion PDF parse, a TIFF encoder out-of-bounds read, uninitialized TIFF-decode pixels) that GitHub's dependency scan matched against every `pillow<=12.3.0` pin in the pack. Universal Modder now pins `pillow==13.0.0` (its own 178 tests pass on it; the refresh tool carries the new pin) and the two opt-in `img2threejs` integrations (`vision`, `glb_character_pipeline`) allow `<14` with `uv.lock` upgraded to Pillow 13.0.0 and certifi 2026.10.19 (a critical certifi advisory). The code in those integrations uses no removed Pillow API and compiles.
- **Your `Tools` and `Modding` folders reviewed.** Nothing from the bench is bundled (about 5 GB of third-party binaries). The modding-bench map lists the new Noita, Risk of Rain 2, Roblox and `_downloads` (ReShade, UE4SS experimental, AssetStudio source, VS Build Tools) entries and notes that the `Tools` snapshots can lag the pack's pins (REA 6.5.0 vs 6.7.0). CLI-Anything, anti-slop and jevgrep stay documented companions; each is still its latest release.
- **174 canonical skills total** across all six provider trees; 151 release contract tests pass.
