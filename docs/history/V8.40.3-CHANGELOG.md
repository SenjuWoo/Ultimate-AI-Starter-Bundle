## 8.40.3 (2026-11-12)

- **Add-ons left behind by a Blender update are reported.** Blender keeps user
  add-ons per minor version; a store or package update replaces the program and
  starts an empty profile, so an MCP bridge or an exporter silently stops
  loading and only an interactive first start offers to import the old ones.
  `app_paths.py` names the missing add-ons with the folder they are in and the
  folder they belong in, and the doctor warns. The profile is the app's own, so
  nothing is copied for you.
- **The doctor and the PATH fixer agree on what is dead.** The doctor counted a
  folder that a tool creates on first use (`.dotnet\tools` in your profile) and
  told you to run a command that keeps it. It now takes the user list from the
  fixer, and reports machine-wide entries separately, with the note that they
  need an administrator.

The bundle still ships 81 canonical skills.
