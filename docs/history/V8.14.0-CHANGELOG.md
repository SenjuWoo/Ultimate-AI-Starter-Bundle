# v8.14.0 — parked task servers, history that survives, no shadowing launchers

173 canonical skills across five provider trees (one new project-intel reference
card, no new skill-index entry). Personal preferences, selected models, trust,
roleplay profiles and verified local skill overrides remain user-owned.

## Task-specific MCP servers no longer load in every chat

Measured 2026-10-15 on the maintainer machine: Claude's machine-wide config held
RimWorldForge, AvatarForge, Melty and the GitHub server; Codex held AvatarForge,
Melty and GitHub; Hermes' default profile held AvatarForge. None were catalog
components, so the doctor said nothing. A connected server puts its tool list in
every chat of that provider, used or not.

- `BUNDLED-TOOLS/PROFILES.json` gains `global_scope_guard`: rules matched on what an
  entry LAUNCHES (command, args, URL), never on its name. Entries already switched
  off, personal servers and the always-on core are never touched.
- `TOOLS/Set-McpProfile.ps1 -Park` saves an exact copy to the bundle state file
  (`parked-mcp.json`; credentials stay in it and are never printed), verifies the
  copy, then removes the machine-wide entry. `-Auto -Path <project>` puts a parked
  server back for the one project whose files match; `-Unpark <id> -Path <project>`
  does it explicitly. `-Park -CheckOnly` lists without writing.
  `UABS_KEEP_GLOBAL_MCP=<id>` keeps one machine-wide on purpose.
- The installer parks after its profile repair. The doctor now fails while a task
  server is machine-wide; Hermes' native profiles are reported, never edited.
- The official GitHub server is parked where the `gh` CLI is signed in
  (`only_if: gh-ready`): its 46 tools do nothing `gh` does not. One predicate,
  `Test-UabsGithubMcpParked`, is shared by the registrar, the installer's
  handshake step (which would otherwise fail the install) and the guard.
  `-Enable github -Path <project>` brings it back per project.
- Verified against the current Claude Code MCP documentation: there is no global
  off switch for a user-scope server (only a per-project disable list), so moving
  the entry out of user scope is the only way to stop it loading everywhere.
  A parked server appears in the next chat opened in the project (or after `/mcp`
  reconnect); the tool's own CLI works immediately.
- Host-owned tools are left alone: native computer-use (a default-off built-in; the
  transcripts show two permission requests and no actions), the app's session and
  sidebar tools, and desktop extensions such as Desktop Commander.

## A shadowing npm launcher

CodeBurn 0.9.23 in the user npm prefix came first on PATH and shadowed the 0.9.27
the pack had installed in another prefix. The cleaner handled only one direction.
It now removes an older copy of a pinned package from either known prefix, after
taking a verified recovery copy (and refuses to touch an equal or newer one), and
`Clean-StaleState.ps1` prunes old recovery copies. The doctor judges the launcher
that actually runs first on PATH.

## A Python that is not Python

Stock Windows 11 puts a `python.exe` alias on PATH that only opens the Microsoft
Store. The installer's runtime check accepted it as "Python present", so a fresh
machine without real Python never got one; `Build-Release.ps1` called it too. Both
now use `Get-UabsPythonExecutable`, which runs each candidate. The machine map adds
one line naming the real interpreter, only on machines where the stub comes first.

## Chat history

- `TOOLS/Backup-AiHistory.ps1` copies, and never deletes, Claude, Codex, Grok and
  Hermes transcripts to a folder of your choice; the installer runs it when one is
  configured. Codex's live SQLite thread database is deliberately not copied.
- The Claude starter settings raise `cleanupPeriodDays` to 365 (the default is 30,
  and 0 disables persistence entirely, so it is never used).

## Project intel

- New card for Melty mashups and cross-engine character swaps, distilled from the
  operator's first mashup: route choice, UE4SS on a modified UE 4.25 shipping
  build, bone discovery and retargeting, secondary-motion springs, the extractor,
  and the test/approval loop. No source-game asset, unpublished code, machine path
  or build-specific offset is included.
- Lessons are recorded as workflow -> tried -> result -> cause -> what worked ->
  recheck. A measured efficiency section corrects two readings of CodeBurn's report:
  unused MCP tool names cost about $0.02 over six sessions, while one 27-hour thread
  cost far more; and the "edits more than reads" ratio counts Read/Edit calls only.
- `coding-discipline`: read before editing and search callers; read the error
  before retrying and never retry a command unchanged.
- Start/resume prompts: grammar fixed, the owner's wording kept, and a line added so
  the agent switches on a parked task tool itself.
