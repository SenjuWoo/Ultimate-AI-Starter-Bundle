## 8.42.1 (2026-11-13)

- **An install with Hermes open no longer fails on a pin it deferred on purpose.**
  While Hermes or its gateway is running, the installer leaves Hermes profiles as
  they are and records that it did. When a pinned server changed in the same
  release (Context7 4.5.0 -> 4.7.0 in 8.42.0), the final doctor then failed the
  whole install on the profiles still carrying the old pin. The doctor now reads
  the recorded deferral and reports those profiles as a warning that says to close
  Hermes and its gateway and run the installer again. A stale pin without a
  recorded deferral still fails.

The bundle still ships 81 canonical skills.
