# v8.29.5 - waiter timeout survives a denied child kill

Skill payload: 129 canonical skills, six provider trees.

The 8.29.4 docs-only CI job failed on the Python 3.15 pack gate, not on a
product install. `TESTS/Test-GitHubVerdict.ps1` simulates a hung `gh` request;
`TOOLS/Wait-External.ps1` called `Process.Kill()` and Windows denied it inside
that job boundary. The exception replaced the intended timeout verdict.

- `Wait-External.ps1` now treats the child kill as best-effort and still throws
  `GitHub request timeout`, so the waiter reports `verdict=unknown` and exits 3
  on the deadline instead of surfacing an access-denied exception.
- `TESTS/Test-GitHubVerdict.ps1` passes all **20 cases** locally under Windows
  PowerShell 5.1, including the hung-request deadline case.
