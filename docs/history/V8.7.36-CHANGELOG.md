# v8.7.36 — search, prefix, and wait

## Search

`_CANONICAL-SKILLS` remains the file agents should read. The five generated
copies under `1-TAILORED-PROVIDER-TREES/*/COPY-TO-SKILLS-DIRECTORY/skills/`
stay tracked, because the installer copies them and `MANIFEST.json` hashes
them. Default ripgrep now skips that directory. Provider files outside it,
including Hermes profiles, stay searchable. A brand-new skill path is
untracked and ignored, so it needs `git add -f`. The release contract compares
every fanned file, not only `SKILL.md`. The pack gate proves the
gitignore rule on a machine with no ripgrep, and also calls ripgrep when
it is installed.

A root `.cbmignore` keeps codebase-memory off those generated copies, release
artifacts, and caches. Do not regenerate it with the Skyrim asset writer.

## Prefix

The wired preamble is the soul, a CRLF blank line, and the AIO contract.
`test_wired_preamble_prefix_is_stable` pins that byte string. An intentional
edit updates the hash in the same change. The block has no date and no
generated token.

## Wait

`TOOLS/Wait-External.ps1` waits on a local process, or on
`gh run watch <id> --compact --exit-status`. A failed GitHub run then fetches
`gh run view <id> --log-failed` once. No model call and no retry loop.
`token-efficiency` and `release-checklist` point at it.

## Free routes left off

`openrouter/free` picks a free model at random. A $0 OpenRouter account is
50 requests/day and 20/minute. Cloudflare's free pool is 10,000 neurons/day,
not a token allowance. Those facts are recorded so the main model is not
routed through them. Checked 2026-10-06.
