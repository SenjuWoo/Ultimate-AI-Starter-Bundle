## 8.43.0 (2026-11-13)

- **Smaller skill listings, nothing uninstalled.** Every installed skill puts its
  description in front of every request, and Claude Code drops what does not fit
  its listing budget. `TOOLS/skill_scope.py` (run by the installer) applies
  `BUNDLED-TOOLS/SKILL-SCOPE.json`: Roblox specialists, Unity's published skills,
  the Replica pack and the bundle's copy of a skill Claude already ships list by
  name only in Claude (`skillOverrides`), each family keeping its entry point
  described. Hermes named profiles disable the Roblox, Skyrim, Unity and Replica
  families that are not theirs (`skills.disabled`); the default profile is
  unchanged. Adult and roleplay skills are never touched, a user's own override
  always wins, and `--undo` turns it off for good. On a full install Claude's
  listing fell from about 42,700 to 21,600 description characters per request.
  The doctor reports the listing size. Decision record: ADR-0009.
- **Every owner command answers in Git Bash.** A forge whose own launcher is only
  a `.cmd` (RimWorldForge's `rwforge`) was invisible to POSIX shells, which most
  agents use. `app_paths.py` now adds the shell-side command beside the owner's
  launcher, and RimWorldForge is registered by name.
- `reverse-engineering` points to the upstream `reverse-api-engineer` agent skill
  that Reverse THIS! 1.17.0 ships with its 0.15.0 pin, including the new default
  of driving the user's own Chrome.
- `docs/TOOL-EVALUATIONS.md` records the repositories added since 8.42:
  teardown, blender-skills 1.3.1 and img2threejs (AssetForge) and
  reverse-api-engineer 0.15.0 (Reverse THIS!).

The bundle still ships 81 canonical skills.
