## 8.44.7 (2026-11-14)

- **Ponytail "off" now switches the plugin off too.** Off parked the copied skill
  folders but left Claude's `ponytail@ponytail` plugin enabled, so its six skills
  stayed in every Claude session and could trigger on any coding prompt. Claude
  Code's `skillOverrides` does not apply to plugin skills. `TOOLS/ponytail_mode.py`
  now sets the plugin switch in Claude's `settings.json` and Antigravity's
  `config.json` (backup first, other keys kept): off/auto disable it,
  lite/full/ultra enable it. It also reads Antigravity's real home
  (`~/.gemini/config`), where six unparked ponytail copies had gone unnoticed, and
  status and the doctor report an enabled plugin at off as a leak. The installer
  no longer forces Antigravity's ponytail entry back on.
- **Tests no longer touch the real provider folders.** Two ponytail tests called
  `main()` without a sandbox home, and a sandbox home still resolved Hermes through
  the real `LOCALAPPDATA`, so a test run copied and re-parked real skill folders.
  An explicit home now confines every provider, and `main()` takes one.
- **Leftovers from older versions are removed on install.** `Clean-StaleState.ps1`
  also removes companion archives that `downloads\companions.json` has superseded,
  Go archives under the pre-8.24 name, and `ponytail-mode.json` (replaced by
  `ponytail-mode\state.json`). A Claude `extraKnownMarketplaces` entry for a bundled
  plugin that still points into a pack folder that no longer exists is repointed
  to the current pack. Backups are still only pruned by the retention limit; live
  toolchain folders and their backups are never touched. Twenty "owner stamp"
  warnings per install are now one line.
- **Catalog pins must match the launch argument.** `super-mcp-router` declared
  2.9.3 while npx still ran 2.9.2, and the freshness audit read only `version`.
  The pin is fixed, `audit_catalog_versions.py` reports such mismatches, and a
  contract test fails on them.
- **Dead references and wrong release advice removed.** `mcp-server-diagnostics`
  pointed at five files that never existed, `release-checklist` at a missing
  checklist and `img2threejs` at a missing script; they now point at real files.
  `release-checklist` no longer advises force-moving a published tag.
- **Skyrim specialists list by name only in Claude.** The family carried about
  8,400 description characters into every session; `skyrim-tool-router` and
  `skyrim-memory` stay described (ADR-0009). Planned listing: ~21,600 to ~14,150
  characters.
- `install_live_skills.py --check` no longer counts plugin-delivered skills, parked
  ponytail copies or Python bytecode as drift. Hermes' `.deleted` folder is not
  treated as a profile. Three files with mixed line endings are CRLF throughout.
- `TOOLS/update_memory_index.py` keeps `MEMORY.md`'s tracked CRLF ending instead of
  rewriting it as LF (the same defect 8.44.5 fixed for the manifest).
- **Antigravity no longer lists superpowers and ponytail twice.** Antigravity loads
  every skill of an enabled plugin under `~/.gemini/config/plugins/<id>` (its own
  embedded customization guide says so), and the installer stages both plugins
  there, yet the copied skill folders stayed: 15 superpowers and 6 ponytail skills
  appeared twice. The native-plugin step now records Antigravity ownership and
  removes the matching copies with a backup, exactly like Claude and Kimi; a
  modified copy is kept. A plugin the installer has not staged yet keeps its copies
  for that run. `-SkipNativePlugins` reconciles Antigravity read-only too.
  `ponytail_mode.py` no longer restores copies at lite/full/ultra where the plugin
  delivers them (Claude, Antigravity).
- `docs/GUIDE.md` said installs only preview the stale-state cleanup; they apply it,
  and the guide now says what it removes.
- **The single content rule names every medium.** SOUL, the AIO contract family,
  `unrestraint-packs`, `adult-character-sheet` and `adult-image-caption` state that
  images, textures, 3D models, sprites, renders, animations and mod assets carry the
  same rule as prose, and that an asset's explicit detail is built in full. The
  Fun-stuff kit prompts, workspace templates and generated paste follow;
  `adult-image-caption` drops its real-person line.
- **`comfy-music`** is registered as a comfy-forge command (ACE-Step 1.5 music,
  `TOOLS/music.ps1`); installs add it beside `comfy-forge` and `comfy-dataset`.

The bundle still ships 81 canonical skills.
