# v8.29.3 - auto-check owner tools and dynamic CI waits

Skill payload: 129 canonical skills, six provider trees.

- `TOOLS/discover_tools.ps1` now reports `skyrim-forge` beside `reverse-this`:
  it resolves `SKYRIM_FORGE_ROOT` or the default
  `%LOCALAPPDATA%\Skyrim-Tools\Skyrim-Forge`, records the Forge Python and
  notes that houseCARL is Forge-owned. The bundle detects the owner install and
  never installs a duplicate.
- `token-efficiency` now explicitly forbids fixed `sleep` polling for CI. A
  fixed wait blocks the session and queues user messages behind it. Use
  `TOOLS/Wait-External.ps1`, which polls dynamically (2 seconds, backing off to
  30) and reports both pass and fail; `release.yml` already waits on the exact
  SHA with a dynamic loop, not a timer.
- `TESTS/test_release_contract.py` pins the discovery keys.
- Verified against the live machine: Forge 6.7.0 found at the default root with
  50 tools and no doctor warnings; Reverse THIS! 1.9.5 found from its kit;
  48/48 Skyrim pack skills still present.
