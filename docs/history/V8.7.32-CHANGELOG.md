# v8.7.32 - obsolete global Impeccable hook cleanup

The reported **Design deep pass** and **Checking UI changes** entries were
not the executable gates retired in v8.7.31. The actual native Codex manifest
registered them as Stop and PostToolUse, respectively. Both had the same old
Bash guard and a CMD-only Windows conditional; PowerShell reproduces its
parse failure even when the project has no Impeccable installation.

The referenced `scripts/impeccable.cmd` is absent from the current shipped
skill. Current Impeccable uses `scripts/hook.mjs` through opt-in project-local
manifests. Retire the stale global registrations rather than starting a new
global engine or replacing project consent with automatic activation.

The shared native-hook migration identifies the complete legacy Unix/Windows
command pair, not a status label or basename. The normal installer and the
read-only installed-state doctor use this same classification. Original bytes
are backed up atomically through the existing retained backup family. Modern
`hook.mjs` handlers, custom commands, other events, metadata and trust settings
are preserved; repeated cleanup makes no further write or backup.

`TESTS/Test-CodexHookRetirement.ps1` executes the real installer in isolated
custom homes. Its added fixture contains both reported legacy entries, a
current handler with the same label and a partially matching custom command.
It checks read-only detection, exact backup hashes, retirement without losing
the current/custom hooks or trust, and idempotence. The existing fresh-home,
missing-Python and malformed-JSON cases remain in the gate.

The two known obsolete registrations were removed locally. Restart Codex so
already-open chats reload their hook configuration; historical failure counts
are not reset. This is not a claim that every independently managed project
hook or rendered UI has been tested. No new dependency, MCP schema, profile
change or broader RTK routing is introduced. The 171 canonical skills and
reviewed local skill overrides are unchanged.
