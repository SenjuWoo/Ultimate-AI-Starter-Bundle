## Correctness

- `Setup-CodebaseMemory-Index.ps1 -Index` now applies scope rules first.
  Missing indexers fail before writes; nonzero native exits cannot print indexed
  success. Plain invocation remains dry-run. Updates are atomic, changed ignores
  get rollback copies, UTF-8 custom rules survive reruns and CURRENT version
  matching no longer confuses 1.2.3 with 1.2.30. No automatic index/watch setting
  is enabled and no existing graph is deleted.
- Privacy scanning uses NUL-delimited UTF-8 Git paths. A Unicode-named tracked
  file containing private data could previously be skipped silently.
- Codex reasoning is a detail of output, not additional output. The local
  usage report stops adding it twice. Historical weighted shares are labelled
  approximate and the cumulative-input/tool-call ratio is not request-size proof.
- Pack parse/encoding checks use the shipped manifest, not ignored old releases
  and large local logs. Both manifest shapes are supported; zero scripts fail.
