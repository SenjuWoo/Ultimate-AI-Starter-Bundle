## 8.42.0 (2026-11-13)

Every pinned third-party component was compared with its latest release. Each
update below was adopted only after its own evidence: release notes, npm/PyPI
metadata (install scripts, licence), a diff of the MCP tools the old and new
versions advertise, and a live call where a host application is needed. The
full record is in `docs/TOOL-EVALUATIONS.md`.

- **Updated:** Context7 4.7.0, Chrome DevTools MCP 1.13.0, Playwright MCP
  0.0.85, shadcn MCP 4.23.0, Firecrawl MCP 3.40.0, Windows MCP 0.8.9, Headroom
  0.44.0, rtk 1.2.0, CodeBurn 0.9.28, Super-MCP router 2.9.3, Playwright CLI
  0.1.24, comfy-cli 1.26.0, REA 6.9.0, Blender MCP 2.2.9, houseCARL 2.1.2 (the
  Skyrim Forge pin), Universal Modder source 3c4ac6c, and Hermes' Unity backend
  MCP for Unity 10.3.0. The shipped Headroom wheel, rtk zip, houseCARL zip and
  Universal Modder wheel are replaced and their hashes recorded.
- **Unity MCP 0.91.0 -> 1.11.1, checked live in Unity 6000.6.** A 1.x project
  stores a per-project port in `UserSettings/AI-Game-Developer-Config.json`, and
  the stdio server must be started on it: with the old arguments it advertised
  no tools, with the port it advertised 13. The `engine-unity` profile now reads
  `{unity_port}` and `{unity_timeout_ms}` from that file. A new 1.x project also
  defaults to the vendor's cloud relay; the profile writes a local entry only
  when the project is set to Custom and stdio, and says how to set it.
- **Blender MCP 2.2.9 ships add-on 2.0.** Checked live in Blender 5.3 against the
  new add-on and the older 1.8, which still works but reports it is out of date.
  The profile's editor step now names `install-addon --addons-dir`, because the
  installer otherwise picks the first Blender version folder it finds.
- **REA 6.9.0 accepts Ghidra 12.2**, so the doctor no longer warns about the
  REA 6.8.0 / Ghidra 12.2 combination once reverse-this has updated REA.
- **Firecrawl keyless claim corrected.** At 3.40.0 no tool works without a key
  (scrape and search did at 3.24.0); it is still not registered without one.
- **comfy-cli instructions fixed.** They told agents to run it on Python 3.13,
  which a machine with only the shared runtime does not have; `uvx` now uses the
  shared runtime. Playwright CLI notes that a machine with Edge and no Chrome
  needs `--browser=msedge`.
- **Held after a re-check:** Impeccable 4.9.0 (its engine still leaks malformed
  script and style bodies into text analysis). OMNI, renamed Contexere upstream,
  stays an evaluation entry with its new repository link.
- **Recommended packs re-reviewed:** awesome-gamedev-agent-skills c6ca6c4 (two
  new skills, standard-library check scripts only) and mattpocock/skills 5863806.
- **A GitHub "Download ZIP" folder is recognised.** The companion registry now
  treats `<repo>-main` and `<repo>-master` as the owner's folder, so a pack or
  forge fetched that way is no longer reported as missing.
- **Supplied repositories evaluated** (CLI-Anything, REA, OBS-MCP, the Opus video
  prompt gallery, the game-dev skills pack, a portable Blender, both Unity MCP
  projects, the Nx/Turbo/Vite/webpack sources, CLibDT and context-mode): what is
  covered, what is watched and why context-mode and OBS-MCP are not bundled is in
  `docs/TOOL-EVALUATIONS.md`.

The bundle still ships 81 canonical skills.
