## 8.37.3 (2026-11-06)

- Companion registry contracts are verified against the published owner layouts:
  Risk of Rain 2 Forge setup is `forge.cmd setup` and its `updates` command is
  labelled check-only; RimWorldForge uses `RimWorldForge-*.zip`,
  `Install.ps1` and `python -m rwforge.cli doctor`; SaintsRowForge points at
  `src/srforge_cli.py`; FaceForge and FollowerForge use versioned release
  markers; AvatarForge uses `AvatarForge-*.zip`; source-only owners no longer
  advertise updater commands that do not exist.
- `TOOLS/companion_registry.py` now validates repository URLs structurally:
  HTTPS-only, exact `github.com`, no credentials, ports, queries, fragments or
  path traversal. Owner trust is a parsed component, not a substring.
- Detection reports `INSTALLED_UNVERIFIED` instead of `INSTALLED` and carries
  `ready: false` with `evidence: markers-only`. A marker, launcher or cached
  version is not installation or runtime proof.
- Versioned GUI executables are matched with an owner-scoped glob
  (`FaceForge-*-STANDALONE.exe`), never a wildcard outside the owner root.
- Regression tests cover foreign and spoofed repositories, escaping markers,
  versioned assets, and the corrected published entrypoints.
- 81 canonical skills total; no companion pin changed.
- RimWorldForge 0.4.1 is released separately with additive, reversible agent
  integration; the bundle only detects and coordinates it.
