# 8.29.12 — tool horizon and discovery fix

- The operating contract now tells every agent to use a better tool it knows,
  even when that tool is not named in the bundle. A new download is checked
  once (official source, license, what it executes) and the verdict is kept
  in the local `SAFE-TOOLS.md`, outside the text sent on every request.
  A later session reuses a verdict of `safe` or one that starts with `safe`.
  Vendoring decisions stay in `docs/TOOL-EVALUATIONS.md`. 130 canonical
  skills total.
- `free_game_tools.py` no longer credits one installed program to a different
  missing tool. A shared Windows search had reported Godot as installed at
  `blender.exe`. Each tool now searches only its own folders. Cargo is
  detected from `cargo`, not from `rustc` alone. No new binary, catalog row,
  or paid service.
