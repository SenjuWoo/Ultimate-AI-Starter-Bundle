# v8.29.1 - workspace doctor reference-scan safety

Skill payload: 129 canonical skills, six provider trees.

The workspace doctor only scans the first 400 text files for references. On a
large project a move candidate could be referenced by a file outside that
window and still be treated as safe.

- `TOOLS/workspace_doctor.py` now returns whether the reference scan completed.
  If it hit the 400-file cap, the report warns and every automatic move is
  downgraded to `review` with a low confidence. Nothing is moved on an
  incomplete reference scan.
- `TESTS/test_workspace_tools.py` exercises the cap directly.
- The real `NemesisCombatAI` audit now reports the cap warning; it already had
  zero automatic moves because the root package and snapshots are
  path-dependent.
