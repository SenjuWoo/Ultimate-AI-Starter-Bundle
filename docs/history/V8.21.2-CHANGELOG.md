# v8.21.2 - required dependency and gate verification

Skill payload: 174 canonical skills, 125 general plus the optional 49-skill
Skyrim pack, across six tailored provider trees. No skill or model downgrade.

The resumed review of v8.21.1 found that a solo Codex install could omit Git
despite native plugins and the final shell doctor requiring it. Provider
bootstrap now provisions that shared prerequisite for every selected provider.
Provider selection and personal settings stay unchanged.

Required gate setup now fails explicitly when its script, Python runtime,
self-test or personal hook configuration is unavailable or invalid. A failed
cached Hermes runtime launch cannot reuse an earlier exit code. Malformed YAML
is preserved, and hook edits copy aliased mappings before changing them so a
personal setting sharing the same YAML anchor stays intact. Serialized values
are checked before an atomic replacement with an exact original backup.

Regression fixtures cover failure propagation, unavailable runtimes, solo
provider prerequisites and real ruamel YAML aliases/comments/newlines. The
serializer is pinned only in the disposable test environment and CI.

A second review pass found two Hermes defects that the installed-state doctor
could not see. Hermes merges its own default into any profile without a `moa:`
key, so a profile that never configured Mixture-of-Agents reported it enabled
with a gpt-5.5 advisor and an `anthropic/claude-opus-4.8` aggregator; every
profile cloned before the pack wrote an explicit block still carried it. The
migration now materializes MoA OFF with the profile's acting model as the
aggregator and cheap OpenRouter advisors, and leaves a block the owner edited
alone. Separately, `Repair-McpPaths.ps1` only checked the default Hermes
config. A Codex update changes its content-hash runtime folder, and five
profile copies kept the dead `node_repl` command while the installer printed
"MCP command paths checked". The repair now scans `profiles/*/config.yaml` and
also repoints directory-only references (`NODE_REPL_NODE_MODULE_DIRS`,
`NODE_REPL_TRUSTED_CODE_PATHS`) under the same unique-sibling rule. Hermes
desktop exports `HERMES_HOME` as the active profile, so the migrator and
installer now walk a profile-scoped path back to the real home instead of
treating one profile as the whole installation. The pack gate also clears an
inherited `PYTHONPATH`/`PYTHONHOME` before its child interpreters start, and
the toolbox gate reads `CallToolResult.is_error` or `isError` on either MCP
SDK generation; a host agent's venv had been shadowing the disposable test
environment with an unpinned `mcp`.

Hermes's native-plugin Git-launch error on the current installed vendor build
still uses the supported copied-skills fallback. Native activation hooks and
commands are not certified. Provider authentication/inference and absent editor
or game integrations remain separate checks. v8.21.2 was published on
2026-10-24 from `f89b17e`; the v8.21.1 tag is unchanged.
