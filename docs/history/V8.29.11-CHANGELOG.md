# 8.29.11 — free game and app starter

- Added `_CANONICAL-SKILLS/game-dev-starter` and fanned it out to Claude,
  Codex, Grok, Kimi, Hermes and Antigravity. 130 canonical skills total.
- The skill is the free-first route for a new game or app: smallest stack,
  procedural asset generators, CC0 libraries, and a real harness before
  content. It points to the existing `img2threejs`, `p5js`, `game-modding`,
  `dogfood`, `visual-verification` and `workspace-organization` skills.
- No paid API, subscription, key, binary or catalog change. The starter is
  documentation and routing; tools are discovered and installed only when the
  project needs them.
- Added `TOOLS/free_game_tools.py` (no network, no install) and
  `TESTS/test_free_game_tools.py`; it reports present tools and official free
  pages for missing ones.
- README and START-HERE now point a new project at `game-dev-starter`.
