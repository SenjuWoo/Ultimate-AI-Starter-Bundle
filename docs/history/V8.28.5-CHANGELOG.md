# v8.28.5 - one-click packs and AI-started tools

Skill payload: 127 canonical skills, six provider trees.

The base install was already one click, but a Skyrim machine still needed
`-Packs skyrim`, and the AI was told to ask the user for a restart before it
could use the new skills. Both made the user do setup the bundle could do.

- `BUNDLED-TOOLS/PACKS.json` now auto-detects the Skyrim pack from the game,
  a mod manager or an existing Forge. Reverse THIS! already auto-detected from
  its kit receipt. `-Packs` forces a layer, `-ExcludePacks` keeps it off, and
  choices are remembered.
- `0-UNRESTRAINT-PACKS/AIO-INSTRUCTION.md` tells every provider's AI to start
  project MCP servers through the toolbox `find`/`describe`/`call` or the
  owning CLI itself, never to ask the user to start a tool, server or
  installer. A host restart is the only request allowed, and only to index a
  new skill.
- `game-modding/SKILL.md` runs the Skyrim pack installer itself and uses Forge
  immediately instead of asking for a restart first.
- README and START-HERE describe the automatic detection. `Test-Packs.ps1`
  now pins auto-on-with-evidence and explicit-exclusion behavior; a release
  contract pins the one-click promise and the preamble sentence.
- Verified on this machine: plain detection reports
  `ENABLED=skyrim,reverse` with Steam app 489830, My Games, Vortex,
  `SKYRIM_FORGE_ROOT`, `SKYRIM_MO2_INSTANCE`, `HOUSECARL_ROOT` and the
  ReverseThis kit receipt. Contracts 156/0, packs gate PASS.
