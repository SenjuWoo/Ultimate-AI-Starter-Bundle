## 8.17.0

- **External tool installs are version-aware.** `houseCARL`, `Spooky's Automod
  Toolkit` and `codebase-memory` no longer report "kept external user install"
  and walk away. The installer reads the installed version (version resource,
  `--version` probe, or the version-stamped folder name), compares it with the
  catalog pin, refreshes an older copy in place after a timestamped backup under
  `%LOCALAPPDATA%\Ultimate-AI-Starter-Bundle\backups`, keeps a same-or-newer
  copy, reports both versions, and never downgrades.
- **Hermes: ponytail's native install can succeed.** The staged plugin now gets
  a `.hermes-plugin/plugin.yaml`; without it Hermes rejected the install with
  "plugin.json declares an unsupported or missing Agent Plugins schema".
- **Claude: stale marketplace paths are repaired.** After the pack folder was
  renamed, Claude's `known_marketplaces.json` still pointed at the old path and
  every plugin command died on "Failed to refresh marketplace
  'superpowers-dev'". The installer now repoints recorded `source.path` and
  `installLocation` values at the same plugin inside the current pack.
- **Skyrim pack: capability wording and ownership.** The pack's instruction file
  drops "never invent framework syntax..." for verify-from-the-plugin/doc/schema
  wording and stops banning SSEEdit/xEdit/Creation Kit outright (prefer the
  CLI/MCP route, GUI on request). A new "Ownership of Skyrim tooling" section
  states that houseCARL, Spooky, xEdit/SSEEdit, LOOT, the Creation Kit and the
  user's own tool root (`S:\Apps\Skyrim Tools` on this machine) belong to this
  pack and to Skyrim Forge, not to the general bundle; README gets a matching
  "Who owns what" paragraph.
- The SPID validator's slash-style trait rows (`F/-T`, `M/-T`) remain the
  documented pre-existing non-defect: `filters.md` section 4 allows combined
  traits, the rows are runtime-proven, and the same 40-file set was already
  recorded at Skyrim Forge v3.4.5. No new validator issues from v3.4.7 - the only
  count change is the removed rows (8,106 -> 8,082 hits). The pack ships 173
  skills.
