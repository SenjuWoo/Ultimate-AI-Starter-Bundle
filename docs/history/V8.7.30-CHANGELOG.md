# v8.7.30 — audited maintenance, local parity, optional media CLI

## Component refresh (2026-09-28)

Headroom 0.39.1, Superpowers 6.4.2, Ponytail 4.10.0, CodeBurn 0.9.25,
Playwright CLI 0.1.21, Playwright MCP 0.0.82, Firecrawl MCP 3.25.5,
Chrome DevTools MCP 1.10.1, Blender MCP 2.1.1, Windows MCP 0.8.6, RTK 0.50.0.

Official RTK and Headroom artifact bytes matched GitHub's published SHA-256
digests. Plugin ZIPs use immutable upstream commits. Default npm CLIs remain
integrity-pinned with lifecycle scripts disabled. Isolated npm dependency
audits of the two CLI updates and three keyless MCP candidates reported no
known vulnerabilities; that is not a guarantee that every dependency is safe.

Superpowers plugin and canonical skills are updated together, including the
new on-demand diagnosing-superpowers skill (171 canonical skills total).
Three-way vendor updates retain bundle patches. Canonical skill references
remain namespace-free for providers such as Grok. The Hermes bridge continues
to exclude foreign provider manifests; reviewed local Impeccable overrides
remain override-owned, not overwritten by the vendor refresh.

Hermes manifest stripping now discovers sibling harness adapters rather than
hardcoding five names, so the new Muse adapter cannot reintroduce gateway
parse errors. A six-adapter fixture verifies stripping and Hermes preservation.
The doctor also rejects a failing bundle-owned Python startup hook even when
Hermes exits zero, instead of silently discarding its startup warning.
Hermes hook installation selects an interpreter that actually has PyYAML and
fails explicitly if none exists, instead of reporting success after a skipped
configuration write. Other providers can still use a lean stdlib-only Python.
Release archives preserve executable permissions for the upstream process-skill
command helpers, including the new inline-execution task-start/task-done pair.

## Compatibility holds

- houseCARL stays 1.9.0: 2.x removes the API the current skills use.
- Impeccable stays patched CLI 3.6.1 / skill 4.1.3: the official engine 0.1.6
  still fails malformed script/style closing-tag tests. Local reviewed 4.3.1
  skill overrides are preserved.
- Perplexity stays 1.2.1 until an authenticated 1.3.0 smoke test is available.
  The candidate rejects keyless initialization; no credentials were read.
- Unity stays 0.91.0 until a real-editor/project compatibility check is available.
- OMNI remains an informational evaluation pin, not an installed component.

The catalog auditor now separates intentional holds from unreviewed drift and
filters the independent Impeccable skill release stream. It no longer mistakes
an engine release for a newer skill version. Runnable self-tests cover both.
