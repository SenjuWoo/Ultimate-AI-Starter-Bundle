## 8.20.1

- **Hermes settings stop pinning models that can rot.** Every auxiliary task (vision, compression, approvals, curator, skills hub, MCP suggestions, title generation) now ships `provider: auto` with an empty model, so it follows whatever main model the user picks. The four-model free fallback chain is gone; the old chain went text-only, then quota-limited, then retired, and each failure was silent. `delegation` follows the main model too. The starter default is `deepseek/deepseek-v4.1-flash-1017` (1,048,576-token context, $0.15/$0.60, text and image input).
- **Dead config removed.** `auxiliary.vision.fallback_chain` is not a recognized Hermes key — it did nothing in any version that shipped it — so the starter no longer ships it, the migrator deletes it, and the `flash-vision` alias (a delisted experimental endpoint) is retired. The main model accepts images, so vision needs no separate route.
- **Compression tuned for a 1M-token window.** `threshold_tokens: 320000` caps compaction at 320k (the ratio alone would wait for ~524k on this window), `target_ratio: 0.20`, `proactive_prune_tokens: 80000`, `abort_on_summary_failure: true`. The cap bounds per-turn input cost and cache invalidation while keeping multi-file work in context; `docs/HERMES-MODELS.md` records the reasoning and the measured catalog facts.
- **Migration follows the same policy.** The profile migrator no longer injects a fallback chain; it clears the superseded pack chain, resets a retired free Ling compression pin to `provider: auto` instead of swapping it for another pin, and removes the unrecognized vision `fallback_chain` key. A user-written chain is still left untouched.
- **The component updater respects catalog holds.** `TOOLS/Update-From-GitHub.ps1` skips any component with a `compatibility_hold` or `security_hold` unless `-Force`, with the hold text printed. houseCARL sat in that updater's default component list while the catalog held it at 1.9.0, so one run could have replaced a working install with an unmigrated 2.x.
- **Live settings synced on the maintainer machine** through `hermes config set`/`unset`: vision fallback removed, compression 320k with pruning on, delegation follows the main model, `updates.pre_update_backup: true`. No config file was hand-edited.
- **174 canonical skills total** across all six provider trees; 151 release contract tests pass.
