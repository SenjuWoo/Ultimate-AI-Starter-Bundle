## 8.50.1 (2026-11-15)

- **Claude's workflow hint names Superpowers skills again.** Claude gets
  Superpowers as a native plugin, and the installer removes the loose copies from
  `~/.claude/skills`. The prompt hook only looked in that folder, so every
  Superpowers specialist (systematic debugging, TDD, brainstorming, plans) was
  dropped as "unavailable" and Claude never saw it suggested. `task_route.py` now
  reads Claude's `installed_plugins.json` and offers user-scope plugin skills under
  their `plugin:skill` name (`superpowers:systematic-debugging`). A plugin switched
  off in `settings.json` offers nothing, and a loose skill of the same name still wins.
- **Leftover cleanup reports what it actually did.** `Clean-StaleState.ps1 -Apply`
  exited 0 when files it planned to remove were locked, so the installer recorded
  the cleanup as applied; "freed" counted planned bytes, removed or not. It now
  exits non-zero when anything could not be removed (the installer still treats
  that as a warning, never a failed install) and counts only what was removed.
- **Cleanup never edits a config it could not back up.** Repointing or removing a
  retired marketplace registration in a provider config swallowed a failed backup
  copy and edited the file anyway. A failed backup now skips that edit and counts
  as a failure. `TESTS/Test-CleanupTruth.ps1` holds both cases with a locked file
  and a folder that refuses new files.
- **The local release gate runs what CI runs.** `python TOOLS/release_gate.py` was
  missing ten contracts CI ran and the extracted Core artifact check, and four
  passing tests ran nowhere (`test_ai_attribution`, `test_mcp_protocol`,
  `test_ponytail_auto`, `test_free_game_tools`; the last one had no script runner
  and executed nothing). The gate and CI now run all of them, and
  `TESTS/test_gate_parity.py` fails when CI gains a contract the gate lacks or a
  test file is reachable from no gate.
- The reference guide lost a 250-line copy of its own Hermes, RTK and claude-mem
  sections that ended in an empty, unclosed collapsible. The README lost a stray
  `</details>`, a second `ownership` anchor and a duplicate Reverse THIS! row. Six
  PowerShell helpers nothing called were removed.

The bundle still ships 81 canonical skills.
