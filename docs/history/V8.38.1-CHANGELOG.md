## 8.38.1 (2026-11-08)

- Installer copies are staged beside the destination and swapped in, with a journal
  phase. A crash midway can no longer leave a half-copied skill in place of the user's
  own: recovery discards the staging folder, removes an uncommitted destination and
  restores the backup. Fault-injection and partial-destination tests cover the window.
- `install` now requires `--apply`, matching `remove`; `plan` and bare `install` stay
  read-only.
- Security and LLM-token cost are independent signals. "Add OAuth login and reduce LLM
  token usage" is a security lifecycle, "reduce AI token usage" is not security, and
  "optimize prompt context tokens" is not security either.
- Skill availability is reported honestly: `available_skills()` scans the selected
  provider's real skills directory (plus receipts) and labels source-only skills as
  `source`, never `installed`. An empty or partially installed provider yields
  `unavailable` instead of a claim.
- Workflow selection is now automatic: `TOOLS/hooks/task_router_hook.py` injects one
  line through Claude `UserPromptSubmit` and Hermes `pre_llm_call`, speaking only when
  the route is not the default lightweight one. It is copied to the install root with
  its two dependencies and wired by `Install-Completeness-Gate.ps1`, so it runs from any
  project directory. `capability-routing`'s description now covers ordinary feature,
  bug, refactor, game and release work.
- Tests: installer 17, task routing 25, hook 7 (real stdin/stdout plus settings merge),
  skill routing 6, release contracts 175. 81 canonical skills unchanged.
