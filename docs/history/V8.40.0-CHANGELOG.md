## 8.40.0 (2026-11-12)

Architecture review: faster hooks, discovery that follows a moved folder, and
launchers that survive awkward paths. Decision record: `docs/decisions/0008`.

- **Hooks cost less than half as much.** The four pre-tool gates now leave before
  loading their modules when a command cannot concern them. Measured per shell
  call: 258 ms before, 113 ms after, with the same decisions on every payload
  that matters. The prompt router no longer comments on a host's own messages
  (a finished background task, a CI event, a local command echo).
- **A source checkout beside its installed runtime is one owner.** The companion
  registry used to call that pair ambiguous and return no path. It now returns
  the runtime and reports the checkout as `source_path`, wherever the checkout
  was moved to. `--print-doctor ID --json` gives the owner doctor as argv plus
  working directory, so no shell string is built from an owner path. The Risk of
  Rain 2 and Minecraft forges now declare their doctors, and asking for the
  doctor of an owner that has none no longer crashes.
- **A moved project is reported.** New `TOOLS/graph_roots.py` lists code-graph
  projects whose folder is gone and names where the project went. The
  installed-state doctor now warns about those and about `PATH` entries that
  point at a missing folder. It reports; it changes neither.
- **Paths with `!`, spaces, parentheses or non-ASCII letters.** `START-HERE.bat`
  could not find its installer from a folder named with `!` when delayed
  expansion was on; both batch files now disable it, and every `cmd /c` the
  bundle builds passes `/v:off`. The graph UI launcher kept its quotes only for
  paths without parentheses. The MCP TOML writer escaped backslashes but not
  double quotes, so an argument carrying inline JSON produced an invalid file.
  A new suite runs real `cmd.exe`, PowerShell, an MCP handshake and a TOML
  round trip through such a folder.
- **Fixed:** the doctor aborted with "Collection was of a fixed size" when a
  later check warned after an earlier one; state files written during an
  install could fail when a virus scanner held the new file for a moment (the
  replace is now retried); the remote installer read an undefined rollback
  folder when the current copy was reused and its installer failed.
- **Removed:** the unused Codex hook-plugin copy of two gates, which had already
  drifted from its source.
- **Forge standard.** `ai-tooling-stack` gains `references/forge-standard.md`:
  what a new or upgraded forge has to provide (doctor, routing, evidence tiers,
  reproducible release). It is a reference loaded on demand, not a new skill.
- The wired instruction text and the MCP profiles are unchanged; the bundle
  still ships 81 canonical skills.
