# v8.22.1 Changelog (2026-10-25)

## Summary

`v8.22.1` completes the parallel-development split between [`SenjuWoo/SkyrimForge`](https://github.com/SenjuWoo/SkyrimForge) (`v6.1.0`) and [`SenjuWoo/Ultimate-AI-Starter-Bundle`](https://github.com/SenjuWoo/Ultimate-AI-Starter-Bundle) (`v8.22.1`, `173` canonical skills total: `125` general + `48` Skyrim pack) so both repositories can be developed and installed independently or together without downgrades or `Test-Installed-State.ps1` ledger drift.

## Key Changes

1. **Skyrim Forge 6.1.0 Pin & Offline Payload**:
   - Updated `BUNDLED-TOOLS/CATALOG.json`, `BUNDLED-TOOLS/PROFILES.json`, `BUNDLED-TOOLS/OFFLINE-MANIFEST.json`, `INSTALL-AIO.ps1`, and `_CANONICAL-SKILLS/skyrim-forge/SKILL.md` to `Skyrim Forge 6.1.0` (`Skyrim-Forge-6.1.0.zip`, `5,098,608` bytes, `sha256: 7220f17a67e7d5828d9ad887d85ab970d5d5c2959e2e2a7d7e6f6f3b8d1ab2ec`).
   - Connected the local `Skyrim-Forge` development checkout directly to `https://github.com/SenjuWoo/SkyrimForge.git` (`main`).

2. **Bidirectional Parallel-Development Bridge (`Install-SkyrimForge.ps1` & `Install-Skyrim-Pack.ps1`)**:
   - `TOOLS/Install-SkyrimForge.ps1` (`Test-ForgeShippedContentCurrent`) now inspects `$InstalledRoot\VERSION.txt` before comparing shipped file hashes. If an existing or parallel `Skyrim-Forge` installation has a strictly newer semantic version than the bundle's pin, `Install-SkyrimForge.ps1` preserves it untouched, invokes its `Install-Skyrim-Pack.ps1` so the newer Skyrim skills win across all providers, and validates `forge doctor` against the preserved version.
   - `Install-Skyrim-Pack.ps1` in `SkyrimForge 6.1.0` resolves Codex's `~/.agents/skills` directory alongside `~/.codex/skills` and updates `%LOCALAPPDATA%\Ultimate-AI-Starter-Bundle\managed-skills\<provider>.json` whole-tree digests whenever co-installed, keeping `TOOLS/Test-Installed-State.ps1` green after standalone `SkyrimForge` skill edits.
   - `Install-AI-Bridge.ps1` in `SkyrimForge 6.1.0` now invokes `Install-Skyrim-Pack.ps1` by default (with `-SkipSkyrimPack` to opt out).
