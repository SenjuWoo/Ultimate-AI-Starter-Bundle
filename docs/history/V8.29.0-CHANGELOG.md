# v8.29.0 - mod workspace repair and public presentation

Skill payload: 129 canonical skills, six provider trees.

The bundle could build a mod and ship a zip, but it had no owner for a messy
project tree and no gate for a public page that was all text. Both are now
first-class.

## Workspace repair

- `mod-workspace-organization` separates source, package, release, state,
  research and caches. A FOMOD package root is path-dependent; one current
  version source; old snapshots under `dist/versions/`.
- `TOOLS/workspace_doctor.py` is read-only by default. It classifies entries,
  reads the current version and root FOMOD version, finds nested caches, and
  checks whether a move candidate is referenced by a text file. `--apply` moves
  only high-confidence unreferenced media/notes/docs, writes
  `.uabs/workspace-backup/<timestamp>/manifest.json`, skips existing targets,
  and never moves a FOMOD root, version snapshot, nested Git repository or
  game/binary asset.
- Exercised against a large read-only mod workspace: a stale root FOMOD, two
  version snapshots, and 5 nested caches including a 1.15 GB build tree and a
  554 MB vcpkg cache. Nothing in that workspace was moved.

## Public presentation

- `mod-presentation` requires real visual proof: 16:9 cover, three gallery
  stills, three local README images with alt text, and a kind-specific shot.
  Character mods need a face/portrait; armor needs front/back/detail;
  environment needs wide/detail; animation needs motion; tools need
  installer/menu shots.
- `TOOLS/presentation_check.py` checks dimensions, aspect ratio, file size,
  README paths and alt text, and fails a text-only page.
- Templates: `MOD-README.md`, `NEXUS-BBCODE.txt`, `PRESENTATION-PLAN.md`.
- The ship gate now records `WORKSPACE LAYOUT` and `PRESENTATION`; a text-only
  public page cannot pass.

## Validation

- `TESTS/test_workspace_tools.py`: safe plan, stale-root warning, nested cache,
  reference-protected screenshots, applied notes move with backup, presentation
  pass and character-close-up failure.
- Contracts pin the two skills, tools, templates, game-modding routes and ship
