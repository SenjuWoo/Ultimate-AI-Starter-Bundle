# v8.7.40 - Windows plugin hooks and audited component refresh

## Hook causes and upgrade repairs

- Reproduced Headroom's command failing because `sh` was absent from the AI
  process PATH, despite Git for Windows being installed. Resolve Git's `bin`
  directory from its actual executable and require both `sh.exe` and `bash.exe`.
  Back up and verify user PATH before adding the directory; preserve private
  process runtime prefixes. Already-running applications need a full restart.
- Two enabled Codex Superpowers installations (curated 6.4.2 and upstream 7.0.0)
  exposed duplicate skills. Reconcile this known pair only when both are enabled
  and upstream is not older. Back up the exact TOML, change only the top-level
  duplicate flag, preserve nested ambient flags and trust. Inventory queries
  honor the selected Codex home and restore the caller's environment.
- Retire exact, unguarded legacy CBM reminder registrations whose body demands
  `index_repository FIRST`. Preserve unrelated/gated hooks and script backups.
  No automatic indexing or watching is enabled. No native hook trust is forged.
- New executable upgrade regressions cover shell discovery, real shell startup,
  multiple Git installations, duplicate detection, backup/idempotence, personal
  settings and custom-home isolation. Existing hook-retirement cases now cover
  unsafe indexing reminders as well as custom/gated preservation.
- Grok's official marketplace update retained Superpowers 6.4.2. The installer
  now installs the tested catalog Git ref when the marketplace remains older.
  Duplicate reconciliation keeps the newer version, verifies a full plugin
  backup before removal, and preserves external/redirected plugin directories.
  Isolated runtime fixtures reproduce the old preference and prove the repair.

## Completion pass (same release)

The release above was interrupted before its gates passed. The completion pass
finished it and audited the live machine's provider logs.

### Defects found in real logs and fixed

- **Codex hooks could never start.** Codex's hook runner
  (`codex-rs/hooks/src/engine/command_runner.rs`) executes Windows hooks as
  `cmd.exe /C "<command>"` unless `commandWindows` is set. codebase-memory's
  installer writes `'C:\...\hooks\cbm-*'`: a single-quoted, extensionless bash
  script cmd.exe cannot run. The repair adds a Git-bash `commandWindows` to such
  handlers inside `CODEX_HOME\hooks` (never elsewhere) and retires the ungated
  subagent reminder that steered every subagent at a profile-gated MCP. The
  regression proves both the original cmd.exe failure and the repaired command
  with the exact Codex invocation.
- **Hooks on a private interpreter.** Running the installer inside Codex put
  Codex's bundled Python first on PATH, so every Claude/Grok bundle gate was
  wired to `~\.cache\codex-runtimes\...\python.exe`, which Codex replaces on
  update. Interpreter selection now skips app-private runtimes unless nothing
  else exists; the doctor flags existing wiring.
- **A skill Codex refused to load.** `skyrim-nexus-publishing` had a plain YAML
  scalar containing `: `; Codex logged `invalid YAML` and skipped it every
  session. `audit_skills.py` now strict-parses frontmatter (PyYAML, or a
  dependency-free plain-scalar rule).
- **Config noise.** `features.rmcp_client` was reported as ignored on every
  Codex config load (1,180+ log lines in one day). Only that exact line in
  `[features]` is removed, with a verified backup.
- **Git shells missed.** `git.exe` resolved from `Git\mingw64\bin` (Git Bash,
  "Unix tools on PATH") did not find `Git\bin\bash.exe`; discovery now walks up
  to the install root and tries every git on PATH.
- **Unpinned download.** Headroom matched GitHub assets without a release tag,
  so the default OnlineLatest mode would fetch upstream latest, not 0.40.0. Its
  tag is pinned and a contract covers every asset-matched component.
- `INSTALL-REMOTE.ps1` printed `Bundle: + <path>`; fixed. It now verifies the
  release asset's published SHA-256 before extracting.

### New capability

- **Self-updating START-HERE.** A newer GitHub release is applied before the
  install: a clean tracking clone fast-forwards; a release copy goes through
  INSTALL-REMOTE's atomic swap (previous copy kept). Dirty clones, offline
  machines, `BundledOnly`, `-SkipSelfUpdate` and `UABS_NO_SELF_UPDATE=1` install
  the local copy. A staging failure exits 20 and falls back to the local copy.
  START-HERE's console no longer sits inside the folder an update replaces.
- **Optional skills; Melty.** `BUNDLED-TOOLS/optional-skills` holds skills
  that never join the default index. `INSTALL-AIO.ps1 -OptionalSkills <name>`
  installs one; later runs refresh it only where it is already present (a
  changed copy is backed up first). The first is `melty-mashups`, which routes
  Melty's MCP flow (prior art, local build and
  test, package/recipe/one-click checks, draft, real media, release, publish on
  explicit approval, install outcomes). Measured 2026-10-10 without credentials:
  `initialize` 0.12-0.16 s (server 1.0.0, protocol 2025-06-18), `tools/list`
  21 tools, 41,702 compact schema bytes; authenticated calls returned
  "couldn't check your token" (503) after 11-15 s while the Melty app was closed,
  which matches the client's 5 s connect timeout. The app registers per-client
  tokens; the bundle never writes, copies or prints them, and the doctor only
  reports where it is registered.
- **Debug logging for games and mods.** A BUILD HYGIENE preamble rule plus
  `observability-first/references/game-mod-logging.md` (Papyrus, SKSE, F4SE,
  BepInEx, MelonLoader, Unity, Unreal, Godot, Minecraft, RimWorld, Roblox, web,
  tools). Every game/mod task recipe now carries `observability-first` and a
  log-path check.
- **Universal Modder 5506516.** Upstream absorbed the UABS UTF-8 and path
  fixes. Rebased UABS deltas: dependency pins, wheel knowledge packaging,
  credential no-echo, registry Steam discovery. Upstream adds local ComfyUI
  generation, SHA-256-checked ffmpeg setup, collision-safe backups, ZenGin
  detection, 160 knowledge notes and the `game-research-websearch` guide. 87
  upstream tests pass (1 skipped: the session hook UABS does not ship); the
  wheel carries `+uabs.5506516` so pip/uv reinstall it over 0.2.0.

## Deliberate limits

- Existing houseCARL, Impeccable, Perplexity and Unity compatibility holds remain.
  Do not call the whole catalog latest when these pins are intentional.
- Windows desktop stays off by default; editor/game/browser MCPs remain scoped.
  No new always-on MCP or indexed skill: 172 canonical skills; Melty is opt-in.
- OpenAI-curated plugins' `agents/openai.yaml` icon paths with `..` and Codex's
  stale rollout-path cache warnings are app-owned and left unchanged.
- An app-owned Codex legacy `notify` command separately logged Windows error 206
  (command line too long). The executable exists; removing it could break the
  desktop app's computer-use completion callback. It is not a bundle hook and
  is left unchanged. This release does not claim to repair that host limitation.
- Old hook-history failures remain historical records. Verify new runs after
  fully restarting apps; a subprocess PASS is not proof an old app reloaded PATH.
