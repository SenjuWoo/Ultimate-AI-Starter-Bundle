# V8.7.28 Changelog

Hermes was starting with the whole Superpowers checkout. That tree's Hermes adapter lives at `.hermes-plugin`, so Hermes walked one level further and tried to parse the Claude, Codex, Cursor, Devin, and Kimi `plugin.json` files as its own plugins. Every gateway start logged those failures. The shared bundle still ships the other adapters, because Kimi installs `.kimi-plugin` from that tree. Only the Hermes git bridge and the installed Hermes copy drop them.

The installer used to restart a running Hermes gateway as soon as the plugin refresh finished. Profile migration runs later and writes `config.yaml`. A running gateway saves the copy it loaded at start, so the migration could be undone. The gateway now stays down until that write is finished. Applying the migration while the gateway is up is refused.

The installed-state doctor now fails on the foreign Superpowers manifests, on a Hermes Context7 package pin that is not the catalog pin, and on a recorded npm spec that is not the catalog spec. `last-github-update.json` merges by component id and keeps a real array, including `installed_version` from the installer.

170 canonical skills. No new dependency or MCP server.
