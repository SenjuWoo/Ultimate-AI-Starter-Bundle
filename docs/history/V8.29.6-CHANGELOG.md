# 8.29.6 — Serena is installed by default

## What changed

- `TOOLS/Ensure-SerenaHermes.ps1` now installs Serena 2.1.0 with
  `uv tool install --force serena-agent==2.1.0` when the executable is missing,
  then registers the Hermes `code` profile entry. Previously it skipped when
  Serena was absent, so a fresh default install could have CBM but no Serena.
- `INSTALL-AIO.ps1` calls that path only when `-CoreOnly` is not set. The normal
  install now has both code-intel servers; `-CoreOnly` keeps both out.
- No schema, skill or runtime change beyond the installer path.

- **129 canonical skills total** (unchanged).

## Verification

- Removed the Serena tool environment, confirmed the executable was gone, then
  ran `TOOLS/Ensure-SerenaHermes.ps1`: it reinstalled 2.1.0 and registered the
  Hermes `code` entry. `hermes -p code mcp test serena` returned connected with
  3 tools; `serena.exe --version` returned 2.1.0.
