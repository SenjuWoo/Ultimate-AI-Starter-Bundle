## 8.37.10 (2026-11-07)

- The shared contract now says what to do when a writing tool refuses an edit:
  re-read the file in full or make a targeted patch, and never push the same
  change through a second writer (Python, PowerShell, node, shell redirection).
  A guard that can be walked around is worse than none, because it hides the
  conflict it was meant to surface. Contract test checks the rule ships to every
  provider and that the workspace copy matches the canonical one.
- Found and reproduced a defect in the Hermes file guard (not in this bundle):
  after a file has been read repeatedly, `_record_successful_read` leaves
  `complete = False` for a genuinely complete read, so `write_file` keeps
  refusing with "was last read with offset/limit pagination" and the recommended
  fix - re-reading every page - cannot clear it. Two paginated reads that cover
  the file also fail to merge when the dedup branch is skipped. Repro, exact
  location and the one-line fix are in `docs/HERMES-FILE-GUARD-BUG.md`; nothing
  in the bundle implements or can enforce that guard.
- 81 canonical skills, no companion pin changed.
