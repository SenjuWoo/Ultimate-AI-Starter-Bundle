## 8.41.0 (2026-11-12)

- **Three prompts instead of two.** `PROMPTS/START-AND-RESUME.md` is rewritten:
  a new-chat prompt, a resume prompt that also covers a fresh chat with no
  history, and a new **upgrade audit** prompt for the day a more capable model
  takes over a project: learn it and record a baseline, audit all of it, rank
  findings by what they cost the user, fix in small verified steps without
  rewriting for taste, and release through the project's own path. The new-chat
  prompt now tells the agent to read the machine map and run a tool's name
  before calling it missing.
- **Creative programs are mapped and installable by name.** `free_game_tools.py`
  says what each program is for and the first command to reach for, and
  `--install <id>` installs a missing one from its publisher's winget package
  (`--install core` is Blender, FFmpeg, ImageMagick and Godot). It installs
  nothing unless a tool is named, never reinstalls one that is present, and
  prints the official page where winget is not available.
- **A missing one is named, not discovered the hard way.** The machine map lists
  which of those four are not installed with the command that adds one, the
  installer prints the same line, and the new installer switch `-CreativeTools`
  installs them in one go. Default installs still add no creative program.
- **`tool-discovery` gains a map**: `references/creative-cli.md` lists Blender,
  Godot, FFmpeg, ImageMagick, Inkscape, Krita, GIMP and the audio tools with
  their use, a first command and the install id, plus the rule to ask the user
  first.
- **Godot from winget is found** even when its folder is not on PATH.
- `ai-tooling-stack` names AssetForge's new `engine-check`, which imports a GLB
  into Godot headless.

The bundle still ships 81 canonical skills.
