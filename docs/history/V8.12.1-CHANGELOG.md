# v8.12.1 - safe private-profile tuning and portable defaults

Date: 2026-10-12. 173 canonical skills total, with five generated provider trees.

- The installer now distinguishes invalid profile input from a deliberately
  empty profile. Oversized/unreadable inputs preserve the last installed block;
  valid empty input can still remove it. An executable test runs the actual
  installer section in an isolated home and proved the old deletion before repair.
- Private preferences belong in the local profile root, not public SOUL/AIO
  sources. Public guidance documents concise, evidence-based lessons, scoped
  capabilities, progress and safe handoffs without copying personal folders.
- Removed maintainer-machine workspace paths from unrestraint-packs,
  windows-workspace-ops and the historical C-game harness reference. The privacy
  scanner now rejects those layouts in both path separator forms, while accepting
  portable relative paths. Twelve audit regressions pass locally.
- Junction cleanup refuses ordinary directories and unlinks live/dangling NTFS
  junctions without deleting their target data. Both unsafe behaviors were
  reproduced before repair in disposable Windows fixtures.
- Include the operator's latest V12.1 main preset unchanged, including its
  formatting/instruction edits and low reasoning setting. Corrected notes name
  the shipped V12.1 SPEECH file and stop claiming the absent V12 parent is bundled.
- Reviewed v8.12.0's public release, exact-commit CI and clean GitHub alerts before
  proceeding. Found local skills/state still at v8.11.1; refresh through the
  ownership-aware installer, preserving native skill ownership and local overrides.
- Backed up 22 externally recreated Codex copies before restoring native
  plugin/built-in ownership. Broken blanket provider-name substitutions were not
  promoted into the canonical tree. Personal gateway selections remain private.

No new global MCP, model replacement, cloud dependency or overlapping tool was
added. Personal profile content and machine-specific verification logs are not
release payloads. Paid inference, GPU generation and gameplay are not certified.
