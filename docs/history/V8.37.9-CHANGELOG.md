## 8.37.9 (2026-11-06)

- CI: every test line now checks `$LASTEXITCODE` itself. `test_companion_registry`
  and `test_task_state` shared one check, so the first could fail silently.
- Evidence is a record, not prose. `cmd:<command> @ <sha> exit=<n>` is the only
  form the controller re-checks; `verified@<sha>` is reported as a claim and a
  `not verified; failed` cell now fails instead of matching a pass word. A bare
  `Verify` with spaces is reported as ambiguous instead of being guessed as a path.
  `resume --fix` refuses to rewrite state while the PLAN is structurally invalid.
- The controller works outside the bundle: `MACHINE-MAP.md` carries its absolute
  path and `state-resumption` uses it, so a project on any drive finds it.
- `refresh-provider-routing.py` rewrites exactly `provider_routing.only`: backup,
  atomic replace, parsed back before the swap, CRLF kept, nested keys untouched,
  no write on an API failure, idempotent. Precision is reported as unknown, never
  assumed to be 8-bit.
- Model documentation matches the shipped config: `docs/HERMES-MODELS.md` and
  `docs/GUIDE.md` no longer call Particle-1 the default or describe a
  planner/worker split; a contract test fails if a page disagrees with
  `VERSION.txt`-adjacent starter config.
- `STATE.md` is 42 lines (was 822): the release notes moved to
  `docs/history/STATE-ARCHIVE-2026-11-07.md`.
- `img2threejs` states when to reach for it: image-to-procedural asset at the
  start of game work, with the limits named.
- README cut from 554 to 209 lines: install in three steps, harness list, add-ons,
  project state, model facts and links. The long Hermes reference blocks moved
  verbatim to `docs/GUIDE.md`, and the contracts that guard them now read there.
- The task controller is installed, not source-only: `INSTALL-AIO` copies it to
  `%LOCALAPPDATA%\Ultimate-AI-Starter-Bundle\tools\task_state.py` and
  `MACHINE-MAP.md` records that path, so it still runs after the checkout moves.
  Verified from an unrelated project whose path has spaces, and after a move.
- Evidence is recorded, not proved: `cmd:<command> @ <sha> exit=<n>` is re-checked
  against the current HEAD; any other cell is reported as a claim.
- `TESTS/test_provider_routing.py` makes the routing safety permanent: dry run,
  nested-key preservation, CRLF, backup, atomic replace, idempotence, malformed
  config refusal, fp4 skipped and unknown precision kept.
- A contract test fails if README, GUIDE or HERMES-MODELS names a different
  default model than the starter config.
- 27 task-controller tests, 171 release contracts.
- 81 canonical skills, no companion pin changed.
