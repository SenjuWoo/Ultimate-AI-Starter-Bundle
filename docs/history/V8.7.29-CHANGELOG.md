# V8.7.29 Changelog

The SillyTavern gateway was the default Hermes profile. That profile loads the full API-server toolset, the coding MCP servers, and every installed skill. A cold SillyTavern turn was about 30,000 input tokens before the scene started.

`TOOLS/Install-SillyTavernGateway.ps1` installs `profiles/sillytavern` and replaces `START-HERMES-GATEWAY.bat`. The launcher checks LM Studio, writes the loaded model into that profile, and starts `hermes -p sillytavern gateway`. The profile's API toolset is vision, image generation, web, file, memory, and skills. Coding toolsets are disabled. Plugins and MCP servers are off. Skills are the gateway note plus adult character sheets and adult image captions.

The profile `.env` is a hard link to the Hermes home `.env` when that file already exists. Keys are not copied into the pack. `env.example` documents the API server knobs only.

170 canonical skills. No new dependency or MCP server.
