## 8.40.2 (2026-11-12)

- **Installed apps and owner forges answer by name.** New `TOOLS/app_paths.py`,
  run by every install: it finds Blender, FFmpeg, Godot, GIMP, Krita, Inkscape,
  ImageMagick, 7-Zip, the Unity CLI and codebase-memory-mcp through the uninstall
  registry, every Steam library, the usual install folders and your tool roots,
  and appends the real folder to the user PATH. An app whose file name carries a
  version (Godot, GIMP's console build) gets a launcher instead. Nothing is
  downloaded; the previous PATH is saved before any change. `-SkipAppPaths`
  turns it off and `-PrunePath` also drops user PATH folders that are gone.
- **A Hermes profile no longer takes a real program's name.** A profile called
  `blender` or `unity` creates `blender.bat`, which starts Hermes; an agent that
  typed `blender` got a chat client, or "command not found" in Git Bash. Such a
  wrapper is renamed to `hermes-<name>`; the profile itself is untouched and
  `hermes -p <name>` works as before. A wrapper that is not a profile launcher
  is reported and left alone.
- **Forge commands.** Each installed forge is reachable from any folder and any
  shell: `assetforge`, `skyrim-forge`, `ror2-forge`, `illusion-forge`,
  `reskate-forge`, `minecraft-forge`, `rbforge`, `comfy-forge`, `comfy-dataset`
  and `re-triage`. The companion registry names each forge's launcher; one table
  holds the real paths, so a moved checkout is repaired by one command and no
  path is written into a batch file.
- **The machine map lists them.** `MACHINE-MAP.md` gains the apps on PATH with
  their versions, the apps that need a full path, the forge commands and the
  repair command. `tool-discovery` tells an agent to read those lines before it
  downloads a second copy of something installed.
- **Frozen machine map in Hermes memory.** When Hermes imports an instruction
  file this bundle wrote, the machine map lands in its memory and is repeated to
  every profile for good. `TOOLS/hermes_memory.py` replaces that block with a
  pointer to the live file, with a backup beside each file; other entries stay.
- **The doctor reports all three**: an installed app that does not answer by
  name, a forge without a launcher, and a frozen map in Hermes memory, each with
  the command that fixes it. Dead PATH entries now come with their fix too.
- **The free game tool report sees the same installs.** `free_game_tools.py` listed
  a Steam or portable Blender as missing and offered the download page; it now
  shares the discovery above, and a profile wrapper named like a tool is not
  counted as the tool.
- **ReSkateForge is a registered owner forge.** The companion registry finds it,
  returns its doctor (`python -m reskateforge doctor`) and `ai-tooling-stack`
  routes ReSkate plugin, park, map and cosmetic work to it. The bundle does not
  install it and never fetches ReSkate Studio; the forge needs your own copy for
  its compile steps.

The bundle still ships 81 canonical skills.
