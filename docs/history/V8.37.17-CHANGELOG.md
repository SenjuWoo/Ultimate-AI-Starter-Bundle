## 8.37.17 (2026-11-07)

- The line-ending checker read working-tree files from this checkout even when
  `root=` named another repository, and the staged path never passed `root` to git;
  `restore_crlf` compared against the module default instead of the `base=` it was
  given. All three fixed, so a test can no longer pass because the wrong repository
  was inspected.
- `TOOLS/check_line_endings.py` gained `--base REV` (commits `REV..HEAD`, what a
  release publishes) and `--root DIR`. CI and the local release gate now run it
  against the last tag, so the release is judged on its own commits rather than on
  the reviewer's working tree; an untagged checkout falls back quietly.
- The pre-commit hook is tracked at `.githooks/pre-commit` instead of only existing
  in one clone. It is opt-in per clone: `git config core.hooksPath .githooks`. The
  previous entry implied it was enforced for everyone.
- `TESTS/test_line_endings.py` rewritten against disposable repositories: working
  tree, staged, a file that was always LF, a converted commit range, and a clean
  history. 5 cases, each asserting the repository it built.
- 81 canonical skills, no companion pin changed.
