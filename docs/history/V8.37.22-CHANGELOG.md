## 8.37.22 (2026-11-08)

- Fixes an install-time hole found by running the real installer: the skill copy step
  runs after the mode step, so a repeat install left the six ponytail skills loaded
  while the recorded mode said `off`, and the doctor correctly refused the install.
  `init` now re-asserts the chosen mode - it parks what the copy step just laid down
  and rewrites the native value - instead of only recording the choice. A deliberate
  `lite`/`full`/`ultra` is still never overwritten.
- `TESTS/test_ponytail_mode.py` asserts the re-assertion: after `init` with `ultra`
  chosen, the native value is `ultra` and the state keeps `ultra`.
- 81 canonical skills, no companion pin changed.
