# v8.28.4 - installed-state doctor provider scoping

Skill payload: 127 canonical skills, six provider trees.

A direct `Test-Installed-State.ps1 -PackRoot .` run checks every provider name
by default. On a machine where Kimi was intentionally not installed, the
doctor reported "Kimi executable missing after provider bootstrap" even
though the recorded install never included Kimi.

- The provider loop now treats the recorded `install-state.json` `providers`
  list as authoritative: a provider outside it is skipped with an info line.
- A provider that IS recorded but has no executable still fails, so a real
  broken bootstrap is not hidden.
- Verified: the doctor passes against the 8.28.3 local install with 0 errors
  and 0 warnings; the full Windows pack gate and release contracts run before
  this release.
