## 8.36.1 (2026-11-06)

- The gateway guard no longer owns files it did not create. `sitecustomize.py` in
  the Hermes store Python is now a delimited block: a foreign file survives
  install, reinstall and uninstall byte-for-byte (BOM and line endings included),
  a marker lookalike elsewhere in the file is foreign, an older whole-file install
  is migrated with a `.uabs-legacy-bak` copy, and writes go through a temp file
  and `os.replace` so an interrupted write cannot truncate the file.
- A blocked `gateway run --replace` no longer reports success when no host came
  back. The recovery spawn is now allowed through (it used to exit on the guard
  that started it, so nothing was running), the host is polled until it really
  answers, and a failed recovery exits 75 instead of 0.
- Tool discovery stops claiming what it did not prove: an owner kit is
  `INSTALLED` (not `VERIFIED`) because the kit directory exists, and an enabled
  MCP entry is `CONFIGURED` (not `CALLABLE`) because no `tools/list` probe ran.
  `CONFIGURED` was added to the state vocabulary and the legacy `FOUND` mapping.
- `TOOLS/discover_tools.ps1` had a literal `{{ ... }}` around its missing-target
  branch, so `exit 1` was a scriptblock literal that never ran; it now exits 1
  properly, treats an unset `$LASTEXITCODE` as success, and the reverse-this row
  concatenates its detail with parentheses instead of loose `+` in argument
  position.
- A failed post-install discovery is reported as `DEGRADED` in the install
  output and recorded under `degraded` in `install-state.json`, instead of
  leaving a clean "complete" line.
- `INSTALL-REMOTE.ps1` restores the previous installation when the new tree's own
  installer fails, not only when the directory move fails.
- The release workflow has a reachable state machine: a tag on another commit is
  a hard stop, a tag at this commit with a published release re-verifies the
  published bytes without rebuilding (companion resolution is "latest" and would
  produce different bytes), and a tag with no release stops for a human.
- `check_versions.py --set` also verifies versionless declarations are present
  before writing, and `TESTS/test_version_bump.py` covers it.
- New tests: `TESTS/test_gateway_guard_lifecycle.py` (10 cases: foreign file
  preservation, idempotent reinstall, BOM/CRLF, legacy migration, exit codes
  through a real subprocess) wired into CI with `test_version_bump.py`.
- `STATE.md` now opens with the current verified state and marks the old
  "not implemented" handoff as superseded, so the first screen cannot contradict
  the entry below it.
- Unrestrained/preamble source untouched; no companion pin changed; 81 canonical skills.
- Erratum for the 8.36.0 notes: the README is 324 lines of front page plus a
  collapsed reference appendix that keeps the load-bearing blocks in the file, so
  the checked-out total is longer than the 324 quoted there. The archived 8.36.0
  history is left as published.
