# Third-party tools and integrations

Catalog entries are not all bundled binaries or enabled servers. Installation
lanes, pins, hashes and compatibility holds live in [CATALOG.json](CATALOG.json).
OMNI and Super MCP Router are evaluations, Windows MCP is opt-in, claude-mem
requires `-WithClaudeMem`, and ComfyUI CLI is optional/user-managed.

Upstream licences and included notices govern each payload; the pack's MIT
licence does not relicense them. Labels identify upstream terms, not an audit
of every dependency. Preserve all included licences and attribution.
